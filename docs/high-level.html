High-Level Detail

A structural view of the agent-state submodule: the file tree diagrams, the file location map, and the platform service map. This page is the starting point for navigating the agent's working files across the Work Credit RAG Platform.

Code Hierarchy & File Diagram

The agent-state submodule contains every agent working file: context, todo lists, session history, skills, coding standards, project architecture, decision records, and the file location map itself. Directories are boxes; files are circles.

Variant A — Detailed Technical Diagram
graph TD ROOT["agent-state/"] ROOT --> ARCH(("architecture.md")) ROOT --> STD(("coding-standards.md")) ROOT --> FILEMAP(("FILE_MAP.md")) ROOT --> GIT(("git-workflow.md")) ROOT --> INSIGHT(("insights.md")) ROOT --> ONBOARD(("onboarding.md")) ROOT --> CTX["context/"] CTX --> CTXM(("context/context.md")) CTX --> TODO(("context/todo.md")) ROOT --> HIST["history/"] HIST --> ARCHV(("history/archive/")) ROOT --> SKILLS["skills/"] SKILLS --> SR(("skills/README.md")) classDef dir fill:#e1f5e1,stroke:#2e7d32,stroke-width:2px class ROOT,CTX,HIST,SKILLS dir
  • ROOT — agent-state/, the top-level submodule directory containing all agent working files.
  • ARCH — architecture.md: end-to-end system architecture, single source of truth for data flow through the platform.
  • STD — coding-standards.md: Python/FastAPI/db/model-serving/Persian rules plus the never-do list.
  • FILEMAP — FILE_MAP.md: single index for finding agent-related text files across the platform.
  • GIT — git-workflow.md: branch structure, PR workflow, submodule workflow, branch protection rules.
  • INSIGHT — insights.md: key decisions, lessons learned, open questions.
  • ONBOARD — onboarding.md: new-machine setup checklist.
  • CTX — context/: agent context directory.
  • CTXM — context/context.md: current agent mission and active component repos.
  • TODO — context/todo.md: current agent todo list (in progress, pending, completed).
  • HIST — history/: archived agent sessions directory.
  • ARCHV — history/archive/: archived sessions such as the DeepSeek-V4 paused mission and audit-fix plan.
  • SKILLS — skills/: agent skill definitions for each component repo.
  • SR — skills/README.md: skill tables mapping tasks to skills and repos.
Variant B — High-Level Black Box Diagram
graph TD CONFIG["Config"] SKILLS["Skills"] HISTORY["History"] CTX_FILES["Context Files"] AGENT["Agent Context"] CONFIG --> AGENT SKILLS --> AGENT HISTORY --> AGENT CTX_FILES --> AGENT
  • Config — configuration and branch rules that feed into the agent context.
  • Skills — skill definitions scoped to each component of the Work Credit RAG Platform.
  • History — archived session records and decision history.
  • Context Files — current mission context and todo lists.
  • Agent Context — central aggregation of config, skills, history, and context files into the agent's working state.
